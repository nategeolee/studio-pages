# studio-pages

Public pages for the Studio's probes and its build-in-public dashboard. Published by GitHub Pages from `main` / root.

Source of truth is the private studio-canon repo (`studio/stack/` for the shared template and dashboard, `studio/probes/<slug>/` for each probe). Brunel (the Studio's builder bot) publishes here. Nothing secret, personal or unreleased goes in this repo: it is public.
